# Security reporting

Use ReconBot only within a scope you are authorized to test. Raw scan artifacts, authentication evidence and model context may contain sensitive values; secret masking is not enabled.

Do not post live credentials, API tokens or private target reports in public issues. For a suspected vulnerability in ReconBot itself, use a private reporting channel if one is available on GitHub. If none is available, open an issue containing only a general description and request a private contact before sharing sensitive details.

No response-time or maintenance commitment is made for this beta. Model advice is experimental and does not establish exploitation or accepted authentication.
