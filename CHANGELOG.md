# Changelog

## 0.1.0 beta — 2026-10-08

- Added the packaged macOS/Linux desktop workspace with ReconBot application identity.
- Integrated scan configuration, live terminal, stage status, reports, findings, artifacts and history.
- Added a force-positioned evidence graph with grouped URLs, exact-address inspection, filtering and adjustable zoom.
- Added independent SQLmap parameter validation with payload evidence and cancellation.
- Added HTTP Basic/fixed POST authentication testing, automatic response comparison and success/candidate-first evidence.
- Added persistent, independently locked discovery/username/password wordlist paths.
- Added English/Turkish interface controls and optional experimental local-model chat.
- Improved partial/failed/disabled scan interpretation, live report reading and small-window form/settings scrolling.

The release tag is `v0.1.0-beta.1`; installer filenames and embedded application version remain `0.1.0`. macOS is unsigned/not notarized. Linux verification used Debian 12 under Xvfb. AI technical correctness has not passed semantic acceptance.
