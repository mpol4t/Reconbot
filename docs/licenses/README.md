# Native dependency inventories

These inventories record the exact npm/Electron/Python/CPython versions used in the release packaging environments. Dependency licenses remain separate from ReconBot's GPL-3.0-only license.

- [macOS Apple Silicon](macos-arm64-components.json)
- [Linux x86_64](linux-x86_64-components.json)

Installer `resources/licenses/DEPENDENCY-LICENSES.txt` includes actual license/copyright texts. Electron/Chromium carry additional runtime notices. The versioned upstream links identify dependency packages and sources; Python runtime versions differ by platform. See [third-party notices](../../THIRD_PARTY_NOTICES.md) and [native build instructions](../../desktop/README.md).
