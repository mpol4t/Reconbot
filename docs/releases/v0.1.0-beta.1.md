# ReconBot v0.1.0-beta.1

ReconBot now brings reconnaissance, evidence review and independent validation into a standalone desktop workspace.

## Included

- macOS Apple Silicon DMG/ZIP and Linux x86_64 and ARM64 DEB/AppImage, with a frozen Python backend.
- Scan configuration, live terminal, recorded stage status, HTML reports and run history.
- Findings filters and an interactive evidence graph with grouped discovery URLs and exact-address inspection.
- Independent SQLmap parameter validation and HTTP Basic/fixed POST authentication tests.
- Persistent wordlist paths with save/lock/unlock controls.
- English/Turkish interface and optional experimental local AI.

## Start

Download your platform's package and follow [getting started](https://github.com/mpol4t/Reconbot/blob/main/docs/getting-started.md). External scanner tools, wordlists and optional model servers are separate prerequisites. Installer filenames and the embedded app version remain `0.1.0`; this release is marked as a prerelease.

## Verification and limits

533 Python tests/69 subtests, 45 desktop unit tests and native macOS/Linux package checks passed locally. Four synthetic labs cover positive/negative discovery, SQL and authentication cases. See [recorded evidence](https://github.com/mpol4t/Reconbot/blob/main/docs/testing.md).

Mac packages are unsigned/not notarized. Linux was exercised in Debian 12 on x86_64 and ARM64 under Xvfb, not on every physical desktop. Intel macOS and Windows are not packaged. Report explanations currently use Turkish. Dynamic CSRF/JavaScript/MFA/SSO form flows are unsupported. A scanner match or automatic login candidate is not confirmed exploitation/authentication.

AI remains experimental: the tested local models produced incorrect CVE and verification advice, and semantic acceptance failed. Scanning/reporting/validation work independently of AI. Values are not secret-masked.

Assets include installer packages, a clean source ZIP and SHA-256 checksums. Use only against authorized targets. Original code is GPL-3.0-only; copyright © 2026 Polat (mpol4t). Dependencies retain their licenses. The release-specific source ZIP and build scripts are provided alongside the installers.
